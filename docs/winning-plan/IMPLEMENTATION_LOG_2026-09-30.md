# FireAtlas local implementation log

**Scope:** local work in the perfected plan using existing files and installed tools. No datasets or dependencies are downloaded; no publishing, deployment, external review, or score claims are made here.

## Starting evidence

- The existing worktree already contains user changes in the scorecard, static bundle, static export, calendar verifier, and supporting tests. These are retained; overlapping files are reviewed before edits.
- Standard database observations: 456,202 MODIS rows from 2006-07-01 through 2026-06-30 and 1,537,960 Suomi NPP VIIRS rows from 2012-07-01 through 2026-06-30. NRT feeds and NOAA HMS rows exist separately and are not mixed into this historical pair.
- Per-region export ledgers include reconstructed row-only MODIS months from 2006-07 through 2022-07 and VIIRS months from 2012-07 through 2022-07. Verified request-metadata complete windows begin in 2022-07 and extend through 2026-06. Earlier positive detections do not establish complete coverage.
- Current calibration artifacts contain 41 eligible MODIS 61.03 / VIIRS 2 month pairs. At the start of this work, grouped leave-one-year-out summaries showed 17/41 (41.46%) and 16/41 (39.02%) coverage for monthly-ratio factor intervals, while model selection and reported performance reused the same folds. These were not prediction-interval coverage estimates. The short paired record does not support independent prediction-interval calibration.
- `calendar_v2.py` still begins history at 2010 by default, only moves earlier for incomplete reconstructed MODIS exports, and searches baselines from 2010. The currently imported row-only MODIS archive begins in 2006.
- The browser reads `month.estimate_type` in bridge and share-card rendering, but monthly API records do not currently provide that field. Percentile ranks are emitted for one-year baselines even though the verdict says the comparison is unusable below ten years.
- Six MCD64A1 case-month checks use Burn Date rasters and hash plus raw-value-cross-tab the paired QA rasters. The six clipped QA samples have zero coordinate mismatches or unpaired pixels; no QA bits are decoded and no QA filter is applied. No product guide or QA-bit specification is stored locally, and `gdalinfo` identifies a byte GeoTIFF without flag semantics.
- Existing local-rubric estimate is 71/118 and engineering tracker is 41.6/100; both remain internal estimates. Current gates and weights are in `docs/winning-plan/src/02-gates-and-scoring.md`.
- A previous local audit recorded 113 tests passing in about 4.1 minutes. This is historical evidence, not a fresh run for this implementation.

## Results and decisions

### 2026-09-30 release and data-access changes

- Updated the regional calibration artifacts from the current local archive. Each region has 41 version-matched MODIS 61.03 / VIIRS 2 overlap months, nested year-held-out evaluation, and daily plus seasonal contiguous-gap reports. Nested selected-pipeline median absolute log errors are 0.304 for Northern California and 0.322 for Punjab–Haryana; median full-year absolute errors are 25.2% and 26.3%. Production choices fit from all available overlap months are `annual_ratio` and `monthly_ratio`, respectively. Prediction intervals are withheld with zero independently evaluated pairs. The 2012 transition remains awaiting request-verified source exports.
- Regenerated the MCD64A1 report. It inventories all 12 local Burn Date/QA pairs (24 TIFFs), uses six pairs in the dated demo checks, and keeps the other six outside those footprints. The official Collection 6.1 guide defines QA bit 0 as land, bit 1 as sufficient valid data, bit 2 as shortened mapping, bit 3 as contextual relabeling, and bits 5–7 as special conditions. Across the six checks, all 9,207 positive Burn Date pixels meet the land/valid-data rule; no positive burned pixel is excluded. The report separately counts 1,251,763 strict full-period unburned pixels and records unburned exclusions by primary reason. Same-date co-location sums 1,205 MODIS and 333 S-NPP common-grid cell-days in Park 2024; it is not pixel agreement or independent validation because MCD64A1 uses MODIS active-fire inputs. A lack of co-location does not establish fire absence.
