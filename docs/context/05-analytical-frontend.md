## Explore static visualization lifecycle

The static shell starts `explore-static.js`, which owns the archived map, region/year/month/source controls, monthly bars, daily UTC heat calendar, exact count table and calendar download. It hides the live-only `study-workspace` rather than exposing its inert placeholders. `combined-static.js` remains a legacy table viewer and is no longer Explore's entry point. `static-atlas.js` is an older unused viewer; do not load two owners for the same map.

Exact raw totals come from the separate `data/explore/` publication, generated by the unchanged authoritative `core.calendar` for joint/MODIS/S-NPP and both fixed regions, 2006–2026. They retain null/partial/complete and documented product-gap states. Point samples are loaded independently from the existing analytical observation bundles and retain their original row eligibility and 200-per-day cap; they do not determine chart totals. Vegetation/land-cover imagery is optional context. Missing imagery leaves local points and exact counts usable.

Applied selections have a serial guard and fresh raw method/unit/release/file identity. Draft controls do not change results until Apply; editing invalidates pending responses and disables view-changing actions. Retry repeats the failed selection rather than the last successful URL. Missing map-library or imagery enhancements leave exact calendars and downloads available. Date/map/chart and Back restoration share one selection; handoff links use canonical route templates. Polygon, custom-area, shorter-interval and unsupported-source incoming requests cannot silently become full-region/month counts: the UI gives explicit unavailable state and a full-region recovery action. Static controls cover the published standard products; other streams/custom AOIs remain available through the local service. Partial/unknown dates are not styled as complete zero days. Daily heat colors reuse the shared yellow-to-red palette with contrasting text and a numeric legend; the logarithmic scale stays fixed across months of the selected source/year. Explore day styles explicitly outrank shared button styling, including hover and selection.

## Lazy tab lifecycle

analytical-panels.js defines research/evidence tab configurations and mounts legacy controllers into scoped HTML templates. FireAtlasPanels.define registers a mount function. A lifecycle proxy provides scoped document/window/fetch/timers and registered maps/adapters.

On deactivation it disables callbacks, clears timers and aborts pending work; disposal removes listeners/maps. Cached panels are keyed by context signature; aborted panels must be rebuilt. select uses a serial token so late script loads cannot replace a newer tab.

When adding a tab or async controller: use scoped APIs; register map cleanup; avoid global DOM queries escaping the panel; guard delayed responses; and preserve keyboard tab navigation. Treat this as a component lifecycle even though it is not React.

Investigation puts the primary sensor, split-view and map-type controls above the map; scale, mask samples, landscape and additional analysis use disclosures. The Park platform case follows the main workspace. When a local session is owned by another tab, an explicit Continue here action transfers control and retries the same study rather than silently taking ownership or narrowing dates.
