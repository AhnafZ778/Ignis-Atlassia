What works on mobile?

The interactive globe, date and satellite filters, atlas, calendar, research tools, exports and fictional commander/crew exercise use the same application server as desktop.

Connection: the globe and analysis pages need the server. Only a prepared Training Lab tab supports saved-exercise offline reload. When launching offline elsewhere, the app shows a reconnect screen.

App format: an installable web app. There is no Android APK, iOS native build, background GPS tracking, push notification service, or shared commander/crew session. Device positions and routes in Training Lab are simulated.

Before presenting: install using a reachable HTTPS address and test the actual phone. A phone’s localhost points to the phone, not your laptop. A laptop LAN address can show the online website but does not provide secure installation or service-worker offline behavior over plain HTTP.
