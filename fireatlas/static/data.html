Exact files for the historical comparison

In NASA Archive Download, request CSV for MODIS Collection 6.1 and VIIRS 375 m / Suomi NPP. Request July 1–31 separately for 2022, 2023, 2024 and 2025: eight files in total. The archive may not show a processing-level selector; check each delivered CSV's version before importing it as standard.

Use the bounding box west −122.2, south 38.8, east −120, north 41. This single area covers both pilot regions. Import each file with its matching source and month, and enter that exact bounding box. Only assert a complete month when NASA’s export covers the entire requested period and area. An already requested July 2021 file remains a valid optional baseline.

The daily text archive from your screenshot uses a separate Earthdata Login; a MAP_KEY does not sign you in. That login-based route is not automated by this harvester. Landsat, WMS and KML are not needed for this comparison.
